## Folder Layout

Each assignment has its own folder with a README, the original specification PDF when available, and source code when available. Assignments 2 and 3 include the specification converted to Markdown in their README, with supporting images in `assets/`. Assignment 3 follows the same layout as Assignment 2. Assignment 4 includes the [original PDF](./assignment-04/specification.pdf), a requirements summary, and a [reading guide](./assignment-04/PREPARATION.md).

Code is added after the due date. Current CPSC 231 students must not copy or submit it.
